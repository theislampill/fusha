# Staged explanation (learner-facing)

**Stage 1 — a word is a root wearing a pattern.** The root (e.g. س ج د)
carries the dictionary idea; the pattern arranges it into a word shape.

**Stage 2 — some letters belong to the pattern, not the root.** In مَسْجِد
the م comes from the pattern مَفْعِل (place-noun shape). Same for مَكْتَب
and مَجْلِس: new root, same reusable shape.

**Stage 3 — but never trust the shape alone.** مَلِك also starts with م —
and there the م IS part of the root م ل ك. Only the word's certified root
tells you which letters are radicals.

**Stage 4 — grammar letters are a third layer.** ال in المَسْجِد and the
ي in يَسْجُدُ belong to grammar (clitic / verb inflection), not to root or
pattern.

**Stage 5 — when we don't know, we say so.** If the root isn't certified,
the colouring honestly abstains instead of guessing.
