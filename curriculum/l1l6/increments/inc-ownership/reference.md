# Reference — root / pattern / affix letter ownership

Owner classes: `root` (radical), `pattern_augment` (template letter),
`clitic` (proclitic/enclitic from the closed inventory), `inflection`
(person/number/tense/mood affix). Short case vowels are hover-only.

| Surface evidence | Ownership consequence |
|---|---|
| certified radicals (evidence ladder) | those letters are `root`, in order |
| letter fills a template slot not in the radicals | `pattern_augment` |
| leading ال، و، ف، ب، ل، ك، س (inventory) | `clitic` (peel conservatively) |
| imperfect prefixes أ/ن/ي/ت on a declared verb | `inflection` |
| letter unassignable / doubly assignable | whole-token abstention |
| radical with no surface letter (weak roots) | `hidden_radical` record |

Hard boundaries: initial م is ambiguous (مَسْجِد augment vs مَلِك radical) —
only root evidence decides; rootless particles own no radicals; tanwīn-alef
is never the pronoun نا; a peel that leaves a non-stem is invalid.
