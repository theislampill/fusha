# Reference — apposition typology discriminator

Two adjacent nominals sharing one case with no coordinator between them stand
in a follower relation in which the second carries the syntactic weight of the
first. Four types are distinguished. The total type has referential identity
and no resumptive clitic, and the second nominal must itself be able to bear
the predication. The partitive type names a genuine portion of the first and
requires a clitic resolving back to it. The inclusion type names a quality the
first merely bears, and requires the same clitic. The corrective type discards
the first nominal as a misstatement rather than clarifying it. Because the
total type and appositional clarification are formally indistinguishable, a
configuration licensing both is recorded under a shared label rather than
arbitrated. A pair in which the second nominal predicates a property of the
first is a descriptive follower and is outside the table.
