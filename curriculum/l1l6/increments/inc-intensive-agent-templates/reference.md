# Reference — intensive and habitual agent templates

The intensive templates strengthen the plain agent noun. Where the agent noun
reports someone performing an act, an intensive row asserts that the act is
habitual, professional, characteristic, or excessive. One root can therefore
run a three-step scale: plain agent, doubled-radical intensive, absolute.

Rows carried by this unit:

| row | skeleton | degree |
|---|---|---|
| faaal | R1 R2 ا R3 | habitual / professional; the productive row |
| faaala_taa | R1 R2 ا R3 ة | reinforced, with a non-gender taa |
| mifaal | م R1 R2 ا R3 | excess |
| faul | R1 R2 و R3 | absolute; shared with the quality class |
| faiil | R1 R2 ي R3 | intensified; shared with the quality class |
| fuala | R1 R2 R3 ة | rare, censuring |

Three things the shape does not settle.

The closing taa of one row is an intensifier, not a gender marker, so a form
carrying it may describe a male referent. Gender is therefore read from
agreement elsewhere in the clause, never from the letter.

Two rows are shared with the quality-adjective inventory. The proposed
separator is a transitivity test: the intensive reading holds where an
underlying verb with an object can be recovered. That test is supplied
evidence — it is contestable, since stative roots also license complements —
so a shared row emits a template and leaves the class open.

Two skeletons carry rival templates outright. The augmented row is
letter-identical to the instrument template, a collision the source teaches
without flagging; the rare censuring row is letter-identical to a common
nominal shape. Both rivals are declared in the pack, so those skeletons
abstain.

Finally, when an intensive form is annexed to a following noun, that noun
corresponds to the source verb's object. This unit flags the pairing for
review; it does not re-analyse the clause and emits no government fact.
