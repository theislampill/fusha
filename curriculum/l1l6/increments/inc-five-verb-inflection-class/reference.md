# Reference — الأفعال الخمسة (the five verbs) surface inflection class

| Template | Shape | Class |
|---|---|---|
| تَفْعَلُونَ (tafaluna) | ت R1 R2 R3 و ن | second masc. plural |
| يَفْعَلُونَ (yafaluna) | ي R1 R2 R3 و ن | third masc. plural |
| تَفْعَلِينَ (tafalina) | ت R1 R2 R3 ي ن | second fem. singular |
| تَفْعَلَانِ (tafalani) | ت R1 R2 R3 ا ن | second dual |
| يَفْعَلَانِ (yafalani) | ي R1 R2 R3 ا ن | third dual |

الأفعال الخمسة are the five imperfect-verb inflections built by attaching
و/ا/ي + ن to a triliteral imperfect stem. This pack classifies the SURFACE
inflection class only: it never infers mood, case or a governor — it emits
a class label and a template id only. Occurrence use over a real
Qurʾānic/text token additionally requires the authoritative Naḥw envelope
(the نون may drop under نصب/جزم — that is a Naḥw fact, never emitted here).

The five surface classes are letter-distinct from one another by
construction (person prefix + number/gender suffix), so no cross-class
collision arises within this pack. See `cu-nun-raf-vs-nun-niswa` for the
distinct نون النسوة family this pack never matches (تَكْتُبْنَ has no long
vowel before its ن).
