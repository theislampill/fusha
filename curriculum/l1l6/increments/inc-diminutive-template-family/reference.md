# Reference — triliteral diminutive template (فُعَيْل)

| Template | Shape | Class |
|---|---|---|
| فُعَيْل (fu3ayl) | R1 R2 ي R3 | diminutive_noun |

The infixed ي is a literal TEMPLATE letter, never a radical: a plain sound
triliteral root surfaces as فُعَيْل (كَلْب → كُلَيْب). Matching the shape is
necessary but never sufficient — a diminutive candidate additionally needs:

1. **attested base-lexeme evidence** (`base_lexeme_evidence.attested`,
   basis `qamus_entry_ladder`) that the base word this diminutive is built
   from is a real, attested lexeme;
2. a **licensed diminutive-affix declaration** bound to this template's own
   infix letter (`diminutive_affix_evidence.marker == "ي"`,
   `.licensed == true`);
3. for a **hollow (medial-weak) base**, the weak radical's literal
   restoration in the diminutive template must be explicitly licensed per
   template and slot (currently only R2/و is licensed —
   `weak_realizations.by_template.fu3ayl.R2.و.literal_licensed`); an
   unlicensed or unbound weak restoration is never assumed regular.

This pack authors ONLY the plain triliteral فُعَيْل family (L6.M5.01); it
makes no claim about quadriliteral-base diminutives.
