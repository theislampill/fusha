# Reference — initial-hamza class discrimination

| Function | Seat | Vocalization evidence |
|---|---|---|
| hamzat_qat (هَمْزَة القَطْع) | hamza_qat_alif | written_mark |
| hamzat_wasl (هَمْزَة الوَصْل) | hamza_wasl_seated | written_mark |

Hamzat al-qatʿ (a genuine glottal-stop hamza, أَكَلَ) and hamzat al-waṣl (the
seated helper alif ٱ, pronounced only in isolation, ٱسْتَخْرَجَ) are DISTINCT
initial-hamza classes. The seat and its exact vocalization must be WRITTEN
evidence — normalisation (which regularly strips or unifies hamza seats)
can never decide this on its own. A bare initial alif with no hamza mark at
all is unresolved: it abstains rather than defaulting to either class.
