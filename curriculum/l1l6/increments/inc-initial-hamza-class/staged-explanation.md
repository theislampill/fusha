# Staged explanation (learner-facing)

**Stage 1** — not every letter-initial أ or ا is the same kind of hamza:
أَكَلَ "he ate" starts with a REAL hamza (hamzat al-qaṭʿ); ٱسْتَخْرَجَ
"he extracted" starts with a helper alif (hamzat al-waṣl) that only gets
pronounced when the word starts a sentence.

**Stage 2** — the two look similar unwritten, so we only decide once the
actual written mark tells us which seat it is.

**Stage 3** — a bare alif with no hamza mark drawn at all doesn't secretly
default to one or the other — we say "needs the mark" instead of guessing.
