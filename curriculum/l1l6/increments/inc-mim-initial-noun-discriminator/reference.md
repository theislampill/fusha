# Reference — mim-initial noun discriminator

Nouns beginning with a prefixed mim fall into several classes told apart by
vowels rather than by consonants. A damma prefix points to the derived-form
participles, where a kasra before the last radical gives the agent reading and
a fatha gives the patient reading. The third-form verbal noun is built on the
same damma-plus-fatha skeleton with a feminine ending and therefore coincides
in shape with the patient noun. A fatha prefix over a bare triliteral source
marks the place-or-time class; a kasra prefix over the same source marks the
tool class, whose templates are lexically fixed per root rather than
derivable. Because the prefix vowel is the only formal boundary between the
last two classes, an unpointed prefix leaves the token undecidable, and that
is recorded rather than repaired.
