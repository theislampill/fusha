# Staged explanation (learner-facing)

**Stage 1** — every lesson page you see is compiled from one reviewed unit:
the same source produces the one-line hint AND the deep analysis.

**Stage 2** — warnings travel with explanations: if a topic has a classic
trap, the page must show it next to the rule, not hide it.

**Stage 3** — where scholars genuinely disagree, the page says so. An
explanation that pretends certainty is a bug, and our tests treat it as one.
