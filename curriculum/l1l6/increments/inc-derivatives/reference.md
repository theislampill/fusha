# Reference — nominal derivative classification

Form-I: فَاعِل = active participle; مَفْعُول = passive participle. Derived
forms: مُـ + imperfect stem; penult kasra = active, penult fatha = passive.
Regular masdars: II تَفْعِيل، III مُفَاعَلَة/فِعَال، IV إِفْعَال،
V تَفَعُّل، VI تَفَاعُل، VII اِنْفِعَال، VIII اِفْتِعَال، X اِسْتِفْعَال.
Form-I masdars are lexical — attestation required, never generated.
Place/time مَفْعَل/مَفْعِل؛ instrument مِفْعَل/مِفْعَلَة/مِفْعَال.
All classes gloss nominally. Exact-template matching only (a loose letter
overlap is not a match — تَكْتُبُ is not تفعيل).
