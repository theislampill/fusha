# Reference — quadriliteral (رباعي) templates

| Template | Shape | Class |
|---|---|---|
| فَعْلَلَ (fa3lala_perfect_active) | R1 R2 R3 R4 | Form I quadriliteral perfect |
| مُفَعْلِل (mufa3lil_active_participle) | م R1 R2 R3 R4 | quadriliteral active participle |
| مُفَعْلَل (mufa3lal_passive_participle) | م R1 R2 R3 R4 | quadriliteral passive participle |

A quadriliteral root supplies FOUR independent radicals; R4 is licensed
exactly like R1-R3, one radical per written letter position. The bare Form
I quadriliteral perfect (فَعْلَلَ, e.g. دَحْرَجَ) is letter-decidable from a
plain four-radical shape; nothing about voice or mood is inferred here.

The مُفَعْلِل active and مُفَعْلَل passive participles are letter-identical
once the radicals stand literally after the augment: this pack declares
BOTH rows, so the cell collides and abstention is the honest verdict for
unvocalised text (مدحرج). A three- or five-radical root never borrows a
slot from this template family; the radical count must match exactly or the
match fails closed to `no_template`.

Quadriliteral templates and triliteral doubling/gemination are DISTINCT
families: this pack declares no GEM slot, and `cu-gemination-licensing`
declares no R4 slot, so the two never collide by construction.
