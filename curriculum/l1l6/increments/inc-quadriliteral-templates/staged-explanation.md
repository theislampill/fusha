# Staged explanation (learner-facing)

**Stage 1** — most Arabic verbs have three root letters, but a smaller
family has FOUR: دَحْرَجَ "he rolled (something)" — د ح ر ج, all four
carrying real meaning.

**Stage 2** — the plain past-tense shape (فَعْلَلَ) is just the four
letters in a row with short vowels, so we can read it straight off the
letters.

**Stage 3** — adding مُـ makes a participle, but WITHOUT vowel marks we
can't tell "doing it" (مُدَحْرِج) from "having it done" (مُدَحْرَج) — they
look identical, so honestly we say "could be either" instead of guessing.

**Stage 4** — a root with only three letters (or a stray fifth letter)
never gets to borrow this four-letter shape.
