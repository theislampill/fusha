# Reference — quality-adjective template inventory

The adjective of stable quality ascribes a lasting property to its referent.
Its rival, the agent noun, reports an action underway or an occupation. That
contrast is semantic: it is decided from the intended reading, not from the
shape, because several of the shapes below are shared with other classes.

Rows carried by this unit, written as shapes over the supplied radicals:

| row | skeleton | notes |
|---|---|---|
| faiil | R1 R2 ي R3 | dominant row; shared with the intensive class |
| falaan | R1 R2 R3 ا ن | state row; restricted inflection |
| falaa_fem | R1 R2 R3 ى | the feminine OF the state row |
| fail / fal | R1 R2 R3 | disposition and short rows, letter-identical |
| afal_colour | أ R1 R2 R3 | colours and bodily defects; restricted inflection |
| falaa2_fem | R1 R2 R3 ا ء | the feminine OF the colour row |
| faul | R1 R2 و R3 | shared with the intensive class |
| faaal | R1 R2 ا R3 | doubled middle radical; shared with the intensive class |

Three consequences follow from template membership and are recorded on the
row itself.

Feminine formation is template-bound. The state row does not take a taa
marbuta; it has its own feminine shape. The colour row's feminine drops the
opening augment and closes with a long low vowel and a hamza. Neither is a
suffixation, so neither can be produced by a general gender rule.

Restricted inflection is also row-bound: the state row and the colour row are
barred from nunation and take a low vowel where a genitive would be expected.
The unit emits that restriction as a flag, because the definiteness and
annexation conditions that relax it are not settled here.

Class membership is the part the shape cannot give. Three rows are shared with
the intensive-agent inventory and one skeleton is shared with the elative. The
pack therefore declares the rival rows explicitly, and the two colliding
skeletons abstain: the disposition/short pair because only a vowel separates
them, and the augmented row because the elative reading is decided by a
different unit.
