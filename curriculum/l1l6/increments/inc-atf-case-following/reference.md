# Reference — case following in coordination

Coordination is a two-role relation. One element is joined to; the other is
joined. The joined element does not receive a case of its own: it copies the
case its peer already bears, whatever that case is and whichever connector
links them. The connector contributes meaning — plain addition, sequence with
or without an interval, alternation, correction, contrast — and contributes
nothing to case.

## Field reinterpretation (important)

This unit reuses the registered `pattern_consistency` analyzer, whose input
slots are named for a different construction. The names are reused as
follows, and nothing here abrogates or governs anything:

| pack / input field | meaning in this unit |
|---|---|
| `abrogator` | the coordination connector |
| `ism` / `ism_marking` | observed case of the joined-to element (head) |
| `khabar` / `khabar_marking` | observed case of the joined element (conjunct) |
| `consistent` | the conjunct inherited the head's case |
| `violation_candidate` | the conjunct bears a case of its own — routed to review |
| `lightened_non_governing` | this occurrence is not a coordination reading |

## The encoding limit, stated plainly

The analyzer compares each observed marking against a constant declared in
the pack. A lane can therefore pin exactly one case. But every connector in
this inventory joins heads in every case — that is the whole content of the
rule. The three lanes below are consequently an ENCODING artifact: they fix
which case this unit checks a given connector at, and they assert nothing
about the connector.

| lane | connectors checked here | case pinned |
|---|---|---|
| atf_raf3_lane | و، ثم | raf3 |
| atf_nasb_lane | ف، أو | nasb |
| atf_jarr_lane | بل، لكن | jarr |

The genuine repair is a generic head-and-dependent marking input that
compares the two observed values to each other rather than to a constant.
That capability does not exist in the consumer, which is precisely the
recorded reason this canonical unit was raised. Recording the limit in the
pack is the honest move; quietly pretending the lanes are linguistic would
not be.

## Boundaries

Attachment is supplied, never inferred: if the wrong preceding constituent is
taken as the head, the check is void, and the source material never raises
attachment ambiguity at all. Clause-level coordination has no case to copy
and is declared out of the checking regime. The adversative item leaves the
coordinator class entirely once an attached pronoun turns it into a doubled
abrogator, and is likewise declared out. The six connectors are a teaching
core; the traditional inventory is larger, and several of these items have
documented non-coordinating uses that this unit does not adjudicate.
