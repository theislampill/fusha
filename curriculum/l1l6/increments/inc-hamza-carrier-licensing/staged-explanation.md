# Staged explanation (learner-facing)

**Stage 1** — hamza is a real root consonant, like any other. What varies is
the letter it is written ON.

**Stage 2** — the seat is chosen by the vowels around it, in a fixed order of
strength: kasra beats damma, damma beats fatha. After a letter with no vowel,
the hamza sits bare.

**Stage 3** — because the seat depends on vowels, it can change when you add
an ending. Recheck after every addition instead of copying the dictionary
spelling.

**Stage 4** — this matters for looking things up: two spellings licensed by
this table are the SAME word, not two. And a handful of forms are simply
stored — you look them up rather than build them.
