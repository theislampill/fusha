# Drill — followers: attributive agreement, coordination case-following, apposition typology, wāw function

**Goal:** given a follower construction (an adjective, a coordinated term, an appositive, or a nominal after
وَ), name the FAMILY and the licensing test FIRST, then justify the case or agreement pattern it requires. This
drill covers four coherent follower families: **attributive agreement** (naʿt: case, definiteness, gender and
number copied from the head, with the non-human-plural and indefinite-elative exceptions), **coordination
case-following** (a coordinated conjunct always copies the case of the element it is joined to, whatever that
case is, including the light-vs-heavy لكن split), **apposition (badal) typology** (total, partitive, inclusion,
and the identity-vs-quality boundary with naʿt), and **wāw function discrimination** (coordination vs.
accompaniment/maʿiyya, decided by case, verbal governor, and foregrounding, never by animacy alone). A right
case ending named without its licensing test — or with the WRONG family's test — is unsafe and is never treated
as auto-correct.

> [`../../nahw/procedures/coordination-case-following.md`](../../nahw/procedures/coordination-case-following.md)

> drill only exercises the discrimination-before-expectation invariant they already establish.

**Rule of the drill:** classify the FAMILY and run its discriminator test before you touch a case ending. A
coordinated conjunct's case is never a property of the connector — it is a consequence of the case the joined-to
element already carries, whatever that case is. An appositive's case is likewise never assigned independently;
it is inherited from its antecedent. An adjective's case, definiteness, gender and number are copied from its
head, with two documented exceptions (non-human plurals take feminine-singular agreement; an indefinite,
non-annexed elative stays in its invariable base shape). A nominal after وَ is accusative only when a verbal
governor licenses an accompaniment (maʿiyya) reading — animacy is a strong cue toward the rival coordination
reading, never an absolute gate against accompaniment. Some occurrences give the evidence no way to decide
(a shared case inside an iḍāfa chain; a disputed particle with no interrogative marker to settle its clause
type); those items are answered by naming the construction as genuinely undecidable, not by forcing a pick.

---

## The four families in this drill

| family | signature | licensing test |
|---|---|---|
| **attributive agreement** | adjective copies head's case, definiteness, gender, number | non-human-plural -> feminine singular; indefinite non-annexed elative -> invariable base shape |
| **coordination case-following** | conjunct copies the case of the joined-to element | position between two terms, then case inheritance; light لكن (no shadda) coordinates, heavy لَٰكِنَّ (shadda) abrogates |
| **apposition (badal) typology** | appositive copies antecedent's case | total (identity, no clitic) / partitive / inclusion (both need a resumptive clitic) / identity-vs-quality boundary with naʿt |
| **wāw function discrimination** | coordination (case copy) vs. accompaniment (accusative object) | verbal governor required for accompaniment; animacy is a cue, not a gate; foregrounding of one actor licenses accompaniment even for an animate object |
