# Occurrence-grounding authoring and review rubric

Read before proposing or reviewing exact lesson/Qamus grounding.

- Require exact `quran:s:a:w`, written surface, normalized surface and canonical source identity.
- Surface, root, skeleton or citation-form equality may recall a candidate; none certifies entry, lexeme, sense or occurrence identity.
- Keep entry relation, context-only appearance, sense relation, occurrence and page appearance distinct.
- Bind every proposal to committed witness evidence and its exact segment/fact references.
- Route iʿrāb-bearing claims to independent conclusion-and-reason review; preserve rivals and school attribution.
- Park missing evidence explicitly so it does not block unrelated instructional closure.
- A parked occurrence dimension is not satisfied occurrence evidence. Give it
  a distinct closure basis, publish the parked denominator and forecast
  assumption, and never include it in an unqualified all-dimensions claim.
- Preserve one canonical projection identity across all real P/V/N appearances; forbid page-local factual forks.
- Verify reverse trace, dependency/revocation fanout and public eligibility separately.
- External/MCP evidence is internal triangulation only and never public hover prose or automatic certification.
- Count accepted, rejected, abstained and blocked proposals separately; never report queue movement as grounding.

Record findings by stable class so recurrence can be measured across tranches.
