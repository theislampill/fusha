# F-D compiler fixtures

These files are generated by `tools/fd_compiler.py` from the lane evidence and the read-only corpus. They are proof artifacts only:

- `sufaha-contract.json` is the contract-conformant typed-fact envelope for `2:13:12`.
- `sufaha-normalized-public-payload.json` is the source-safe normalized payload consumed by both HTML views.
- `sufaha-card.html` is the generated compact/expanded proof surface.
- `sufaha-parity-fixture.json` records exact reconstruction, family-payload parity, and entry reciprocity.
- `assets/KawkabMono-Regular.woff2` is the local font used by the render proof.

Regenerate from the lane root with:

```powershell
python tools/fd_compiler.py `
  --sufaha-evidence ..\lanes\FD-dryrun\sufaha-evidence.jsonl `
  --whitelist ..\data\rh_live_01_beta_whitelist.jsonl `
  --entries ..\data\entries.jsonl `
  --v575-verdicts ..\lanes\FD-dryrun\v575-verdicts.jsonl `
  --output-dir qamus\examples\fd `
  --font-source ..\..\w5-board\KawkabMono-Regular.woff2 `
  --report fd-455-report.json `
  --verdict-output fd-455-verdicts.jsonl
```

The command does not write `data/`, a live whitelist, or a runtime surface. The report is candidate-mode only and keeps all live mutation flags false.

When Playwright is available, run the real render proof:

```powershell
node tools/render_fd_sufaha.js
```

The script waits for `document.fonts.ready`, asserts `document.fonts.check`, runs the exact-reconstruction hook, injects the visible proof state, waits 250 ms, and then captures the screenshot. It writes `sufaha-card.png` and `render-proof.json` only under this fixture directory.
