# FAM3 number-word formation fixtures

These repository-owned fixtures exercise the candidate-only number-word
producer. They are not the read-only calibration corpus and do not authorize
source, whitelist, public, or runtime mutation.

The registry is closed and named. A number label, gloss, or morphline cannot
create a fact. Positive rows require a same-entry base, exact written evidence,
and a registered number rule; adversarial rows must remain typed unresolved.
