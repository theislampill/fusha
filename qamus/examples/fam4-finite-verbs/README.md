# FAM4 finite-verb producer fixtures

These fixtures are repository-owned RED-first tests for the finite-verb
producer. They are not Qurʾanic corpus data and never authorize whitelist,
public, or live mutation.

The producer accepts only exact caller-supplied entry forms and the named
Form-I registry patterns. The `qg-subject-pronoun` and `qg-object-pronoun`
classes are shared with the clitic-pronoun composition lane. The
`derivative_prefix_form_v` marker is present for classification only and is
owner-gated to `derived_verbs`.
